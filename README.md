<details id=2>
<summary><h2>🧭 How I work</h2></summary>

_The order I learned in finance: agree on the number, then build on it._

1. **Define the KPIs**: write down what every number means before any chart exists, so everyone reads it the same way.
2. **Clean once, reconcile**: one source of truth, checked against the system it came from, until the totals match.
3. **Answer, then show**: lead with the decision and its cost. The dashboard holds the evidence.
